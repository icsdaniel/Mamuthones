# Mamuthones: The Weight of Bells

A mobile rhythm game built around the Mamuthones of Mamoiada, Sardinia.

## Bell Shake Test

`index.html` is a small phone test for the game's core input, played with one hand: the thumb taps the top and bottom step pads, and a shake of the phone rings the bell. It shows how precisely each input lands on the beat, and how often a hard tap is mistaken for a shake. A Right hand / Left hand switch mirrors the pads.

Open it on a phone at https://icsdaniel.github.io/Mamuthones-/ (GitHub Pages, deployed from `main`). On iPhone, allow motion access when asked.
